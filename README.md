.x* Archive Format
=============
**Pac-Kart is an in progress file editor.**

### 6 Games are known to use this format.
* Motor Mayhem: Vehicular Combat League
* Hot Wheels Velocity X
* Snoopy vs. the Red Baron
* Pac Man World Rally
* Bee Movie Game
* Bigfoot: Collision Course

The goal is to have each game and version traversable, extractable and fully editable.

Pages
============

2 pages are listed.
Main Page: https://pac-kart.github.io/Pac-Kart/  
Array View Page: https://pac-kart.github.io/Pac-Kart/array_view.html

The Main Page is an older version and is not currently being updated.
This version may be replaced with the Array View once all features are added to that version.

The Array View shows a more literal view of how Pac-Kart handles the format.

Main Page
--------
### Features only on the Main Page:

* Model Viewer, Import and Exporter (Pac Man World Rally PC Only)
* Pac Man World Rally Save file Editor
* Texture Viewer and importer (Only some formats)
* Audio Player and importer (Only some formats)
* File View (Only some sections)
